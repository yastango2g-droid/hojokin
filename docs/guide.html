補助金の探し方・申請の流れ

初めて補助金を探す方向けの、一般的な解説です。個別の制度の条件や手続きは、必ず各制度の公式ページ・公募要領でご確認ください。

補助金と助成金のちがい

どちらも国や自治体などが事業者の取り組みを支援する、原則として返済不要のお金です。一般に、補助金は審査があり採択された事業者だけが受け取れます。助成金は条件を満たせば受け取れるものが多いとされます。呼び方は制度によって異なります。

このサイトの見方

  • 補助上限額: 1件の申請で受け取れる最大額です。実際の交付額は、かかった費用と補助率で決まります。
  • 補助率: 対象になる経費のうち、補助される割合です。例えば「2/3」で対象経費が90万円なら、補助額は最大60万円です(上限額の範囲内)。
  • 申請締切: この日までに申請を完了する必要があります。締切前に受付が終わる場合もあります。
  • 記載なし: データに値がない項目です。「無い」という意味ではないため、公式ページで確認してください。

探し方のコツ

  1. 一覧で、地域とキーワード(例: IT導入、創業、省エネ)を入れて絞り込みます。
  2. 目的がはっきりしているときは、トップページの「目的から探す」や「地域から探す」が便利です。
  3. 気になるものは「締切が近い順」で並べ、今月締切も確認します。
  4. 詳細ページの「公式ページで詳細・申請方法を見る」から、公募要領を必ず読みます。

申請の一般的な流れ

  1. 制度を選ぶ: 対象者(業種・従業員数・地域)と、対象になる経費を確認します。
  2. 申請の準備: 事業計画書などの書類を作成します。電子申請では、GビズIDなどのアカウント取得に日数がかかることがあります。
  3. 申請・審査: 締切までに申請します。審査があり、採択されない場合もあります。
  4. 交付決定後に事業を実施: 多くの制度では、交付決定の前に発注・契約・支払いをした経費は対象外です。
  5. 実績報告と受け取り: 事業の完了後に報告し、確定した金額が支払われます。多くの制度は、先に自己資金で支払う「後払い」です。

注意したいこと

  • 採択や交付額は保証されません。資金計画には余裕を持たせてください。
  • 募集内容は変更・早期終了する場合があります。最新情報は公式ページで確認してください。
  • 書類作成の代行や個別の申請相談は、専門家(行政書士・中小企業診断士・認定支援機関など)の業務です。当サイトは情報提供のみを行い、個別の申請のアドバイスや代行は行いません。
